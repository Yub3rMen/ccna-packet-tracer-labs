# CCNA Packet Tracer Labs

A learning portfolio of **Cisco Packet Tracer** labs completed while studying for the CCNA. These are guided practice exercises, documented with the goal, networking concepts, observed verification evidence, and limitations.

## Documented labs

| Lab | Concepts | Evidence |
| --- | --- | --- |
| [01 — DHCP server and relay](01-dhcp-server-and-relay/README.md) | Multiple DHCP pools, DHCP client interface, relay across a routed network | R2 DHCP binding table and PC1 `ipconfig /all` output |

## How these labs are documented

I distinguish **verified results** from configurations that still need screenshots, and I credit instructors whose exercises I used. These are simulations, not production deployments. Files from instructor-provided Packet Tracer activities are not redistributed here.
